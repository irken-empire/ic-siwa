# Shoulders

_**Standing on the shoulders of giants.**_

This project would not be possible without the amazing work of the following projects and their contributors:

## Core Inspiration

- **[ic-siwe](https://github.com/kristoferlund/ic-siwe)** by Kristofer Lund - The original Sign-In with Ethereum implementation for the Internet Computer.

`IC-SIWA` is a fork adapted for the Avalanche ecosystem.

Thank you for the incredible foundation. This project could not exist without your work.

## Internet Computer

- **[DFINITY SDK](https://github.com/dfinity/sdk)** - The tooling that makes building on the IC possible
- **[ic-cdk](https://github.com/dfinity/cdk-rs)** - Rust CDK for Internet Computer canisters
- **[@icp-sdk/core](https://github.com/dfinity/agent-js)** - JavaScript/TypeScript SDK for IC interaction (formerly @dfinity/agent)

## Avalanche & Ethereum

- **[viem](https://github.com/wevm/viem)** - TypeScript interface for Ethereum/EVM chains, powering wallet interactions
- **[WalletConnect](https://github.com/WalletConnect)** - Connecting wallets to dApps seamlessly

## Cryptography

- **[k256](https://github.com/RustCrypto/elliptic-curves)** - secp256k1 elliptic curve implementation in Rust
- **[sha2](https://github.com/RustCrypto/hashes)** & **[sha3](https://github.com/RustCrypto/hashes)** - Cryptographic hash functions

## Development Tools

- **[Nix](https://nixos.org/)** & **[devenv](https://devenv.sh/)** - Reproducible development environments
- **[Astro](https://astro.build/)** - The web framework for the test frontend
- **[Bun](https://bun.sh/)** - Fast JavaScript runtime and package manager

---

Thank you to all the open source contributors who make projects like this possible.
